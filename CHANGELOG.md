# Changelog

## [0.1.0] - 2026-11-07

First release of `lfed`, the command-line host for the education platform.

### Features

- `lfed context list|use|current`: select the deployment context (dev, staging, prod).
- `lfed auth login|logout|status|token`: Auth0 device code login; credentials in the system keychain, or a plain file with `--insecure-storage`.
- `lfed plugin install|list|upgrade|remove`: plugins as signed OCI artifacts. Install by catalog name, `<catalog>/<name>`, full OCI reference, or local path. Pin a version or digest.
- `lfed plugin catalog add|list|remove`: plugin catalogs in `config.yaml`. The built-in catalog resolves bare names; an alias resolves `<alias>/<name>`. Each catalog carries its own Sigstore signer identity.
- Plugin catalog published from this repository as a signed OCI artifact and verified against the `catalog-publish.yml` workflow identity before use.
- Sigstore verification of plugins against the identity in their catalog entry, or `--certificate-identity-regexp` and `--certificate-oidc-issuer` for unlisted plugins.
- `-o table|json|yaml` and `--jq` on every command. `lfed help environment|exit-codes|plugins` topics.
- `install.sh`: downloads the release archive, checks it against `checksums.txt`, and verifies the checksums signature against the `release.yml` workflow identity when `cosign` is installed (`LFED_REQUIRE_SIGNATURE=1` makes it mandatory).
- SDK module `go.ed.linuxfoundation.org/lfed/sdk` for plugin authors: manifest serving, confirmation prompts, HTTP client, output and iostreams helpers.
